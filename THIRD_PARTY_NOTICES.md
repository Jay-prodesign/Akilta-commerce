# Third-Party Notices

This file records repository-level notice posture; exact dependency and license truth is release/tree specific.

The `main` branch began as a bootstrap baseline. Active engineering may exist on unmerged task branches with a different dependency graph than `main`. Therefore do not infer current product-wide dependency truth from this file or the root `package.json` alone.

For any selected engineering/release tree:

- exact direct and transitive dependencies must come from the applicable lockfile/build graph and machine-generated inventory where available;
- third-party license/provenance decisions remain governed by the current AI Commerce OSS/Dependency/License Register and the inherited AKILTA IP/Licensing policy;
- required copyright, attribution, NOTICE, source-offer, or other obligations must be preserved;
- UNKNOWN/no-license material is not admitted into production merely because it is publicly accessible;
- donor/benchmark material does not become reusable source code without exact provenance and license compatibility.

No third-party license is overridden by the proprietary repository `LICENSE`.
